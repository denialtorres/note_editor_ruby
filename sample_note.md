## Features

The editor is designed to be simple and distraction-free, just like the Ubuntu editor in your screenshot.

### Markdown Support

Headers are highlighted in **cyan** for easy visual scanning.

### Clean Interface

- Dark background (easy on the eyes)
- Status bar shows: filename, modified status, cursor position
- Help bar shows keyboard shortcuts

## Try These Commands

1. Press `Ctrl+H` to see the help screen
2. Press `Ctrl+S` to save your changes
3. Press `Ctrl+X` to exit
